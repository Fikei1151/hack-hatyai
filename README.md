# จำลองน้ำท่วมเมืองหาดใหญ่ · Hat Yai Flood Simulator

เว็บจำลองน้ำท่วมเมืองหาดใหญ่แบบ 3 มิติ สร้างเมืองจากข้อมูลจริง (ภูมิประเทศ อาคาร 91,000+ หลัง ถนน คลอง สถานที่สำคัญ) แล้วใช้สมการน้ำตื้น (shallow water) คำนวณการไหลของน้ำบน GPU ตามฝนและน้ำจากต้นน้ำที่กำหนดเป็นเฟส ๆ จะใช้ข้อมูลจริง (ย้อนเหตุการณ์/พยากรณ์) หรือสุ่มสถานการณ์ก็ได้ ผลการรันถูกเก็บลง Supabase

## เริ่มใช้งาน

```bash
npm install
npm run db:start          # Supabase local (Docker) — API :56321, Studio :56323
npm run city:build        # ดึงข้อมูลเมืองจาก API จริง → public/city/hatyai (ครั้งแรก ~3–5 นาที, มี cache)
npm run events:build      # ดึงข้อมูลน้ำท่วมจริงปี 2568/2553 → public/city/hatyai/events.json
npm run dev               # http://127.0.0.1:5180
```

ใส่ค่าใน `.env.local` (ดู `.env.example`) จาก `supabase status -o env`: `API_URL` → `VITE_SUPABASE_URL`, `PUBLISHABLE_KEY` → `VITE_SUPABASE_ANON_KEY`
ถ้าไม่ได้เปิด Supabase แอปยังทำงานได้ และบันทึกลงเบราว์เซอร์แทน (มุมขวาบนจะบอกสถานะ)

## ข้อมูลจริงที่ใช้

| ส่วน | แหล่งข้อมูล | วิธีดึง |
|---|---|---|
| ภูมิประเทศ | Copernicus GLO-30 DEM (ESA) | อ่าน Cloud-Optimized GeoTIFF บน AWS แบบ HTTP range |
| อาคาร 91,273 หลัง | OpenStreetMap | Overpass API (ความสูงจาก tag หรือประมาณจากประเภท/ขนาด/ระยะจากใจกลางเมือง) |
| ถนน, คลอง, บ่อ/แหล่งน้ำ | OpenStreetMap | Overpass API — คลองถูก "เผา" ลงใน DEM ให้ไหลต่อเนื่องจริง |
| สถานที่สำคัญ 281 แห่ง | OpenStreetMap | Overpass API → ตาราง `places` (Supabase + PostGIS) |
| ภาพถ่ายดาวเทียม | Esri World Imagery | tile z15 ทั้งเมือง + z17 ใจกลางเมือง |
| ระดับน้ำ/ปริมาณน้ำ | สถานีกรมชลประทาน X.90, X.174, X.44 ผ่าน ThaiWater (สสน.) | API สาธารณะ (ดูสดได้ในแท็บ "ข้อมูลสด") |
| ฝน | สถานีอุตุฯ สนามบินหาดใหญ่ (ThaiWater) + Open-Meteo/ERA5 | ฝนรายวันจริง กระจายเป็นรายชั่วโมงตามรูปแบบ ERA5 |
| พยากรณ์ 7 วัน | Open-Meteo + GloFAS | ปรับเทียบน้ำท่ากับสถานีวัดน้ำ ณ ปัจจุบัน |

ตรวจสอบกับเหตุการณ์จริง: แท็บผลลัพธ์มีกราฟระดับน้ำที่ X.44 (บ้านหาดใหญ่ใน) จากแบบจำลองเทียบกับค่าตรวจวัดจริงปี 2568 พร้อมเกณฑ์เตือนภัยของกรมชลประทาน (6.0 / 7.4 ม.รทก.)
Google Photorealistic 3D Tiles ไม่ครอบคลุมหาดใหญ่ (ตรวจสอบแผนที่ coverage แล้ว) จึงสร้างเมืองเองจาก OSM + DEM

## ระบบเฟส (Phase)

สถานการณ์หนึ่งประกอบด้วยหลายเฟสเรียงกัน แต่ละเฟสกำหนด:
- ระยะเวลา และช่วงเปลี่ยนผ่าน
- ฝน (มม./ชม. เฉลี่ยทั้งพื้นที่) รูปแบบฝน (ทั่วพื้นที่ / กลุ่มเมฆฝนเคลื่อนที่ / ฝนภูเขา / แนวพายุ) ความแปรปรวน ทิศและความเร็วพายุ
- น้ำไหลเข้าจากต้นน้ำ ณ สิ้นเฟส (คลองอู่ตะเภา 82% + คลองหวะ 15% + คลองวาด 3%) → เฟสต่อกันเป็นกราฟน้ำท่า
- ระดับทะเลสาบสงขลา (น้ำหนุนท้ายน้ำ) ความจุท่อระบายน้ำ การซึมลงดิน
- เหตุการณ์พิเศษ: น้ำล้นตลิ่ง/คันแตก (สุ่มจุดริมคลอง), ท่อระบายน้ำอุดตัน, ทะเลสาบหนุน

ปุ่ม **สุ่มน้ำท่วม** สร้างสถานการณ์ตามคาบการเกิดซ้ำ (2–300 ปี) พร้อมเหตุการณ์สุ่ม (seed เดิมได้ผลเดิม)
ความเร็วเล่น: ⅓x, 1x (= 30 นาทีต่อวินาที), 3x, 10x — แสงอาทิตย์/กลางคืนเดินตามเวลาจริงของสถานการณ์

## แบบจำลองน้ำ

- สมการ shallow water แบบ local-inertial (Bates et al. 2010 / LISFLOOD-FP) + θ-scheme (de Almeida 2012) บน GPU (WebGL2) กริด 20 ม. 720×720 เซลล์
- แรงเสียดทาน Manning ตามสิ่งปกคลุม, porosity ของบล็อกอาคาร, Froude limiter, ก้าวเวลาแบบ CFL อัตโนมัติ
- ฝนเชิงพื้นที่ (กลุ่มเมฆเคลื่อนตามลม), การซึม, ท่อระบายน้ำที่ส่งน้ำกลับเข้าคลอง, ขอบเขตท้ายน้ำผูกกับระดับทะเลสาบ
- พื้นผิวน้ำเคลื่อนไหวตาม **ความเร็วการไหลที่คำนวณได้จริง** (flow mapping): ทิศ/ความเร็วคลื่นและฟองคือผลลัพธ์ของแบบจำลอง
- อาคารที่น้ำท่วมจะเปลี่ยนสีหลังคาตามระดับ (เฝ้าระวัง/อันตราย/วิกฤต) และมีคราบโคลนตามระดับน้ำสูงสุดหลังน้ำลด

## ความแม่นยำเทียบเหตุการณ์จริง (พ.ย. 2568)

เทียบระดับน้ำที่สถานี X.44 (บ้านหาดใหญ่ใน) จากแบบจำลองกับค่าตรวจวัดของกรมชลประทาน:

| ช่วงเวลา | น้ำไหลเข้า | X.44 จำลอง | X.44 จริง |
|---|---|---|---|
| 21 พ.ย. 12:00 | ~330 ลบ.ม./วิ | 3.6 ม. | 3.7 ม. |
| 22 พ.ย. 12:00 | ~1,300 ลบ.ม./วิ | 6.6 ม. | 7.2 ม. |
| ช่วงพีค 24–25 พ.ย. | ~3,000 ลบ.ม./วิ | ~7.0 ม. | 9.97 ม. |

- ช่วงน้ำขึ้นถึงระดับตลิ่งตรงกับของจริงค่อนข้างดี แต่ **ระดับสูงสุดต่ำกว่าจริงราว 3 ม.**
- ช่วงพีค แบบจำลองให้พื้นที่น้ำท่วมราว 52 ตร.กม. และอาคารที่มีน้ำเกิน 30 ซม. ราว 28,000 หลัง
- ย่านใจกลางเมืองยัง "แห้งกว่าจริง": หน้าสถานีรถไฟราว 0.3 ม. ส่วนตลาดกิมหยงแทบไม่ท่วม ขณะที่ของจริงลึกราว 1 ม.

สาเหตุหลักคือข้อมูลภูมิประเทศ DEM ความละเอียด 30 ม. เป็นแบบผิวบน (DSM) ซึ่งรวมความสูงของอาคารและต้นไม้ไว้ด้วย นอกจากนี้ยังไม่มีประตูระบายน้ำ สะพาน และคันถนนในแบบจำลอง

ถ้าจะให้แม่นขึ้น ทำได้ดังนี้:
- ใช้ DTM จาก lidar หรือ FABDEM
- ใส่การแบ่งน้ำของประตูระบายน้ำนาควน/อู่ตะเภา
- ขยายขอบเขตแบบจำลองไปถึงทะเลสาบสงขลา

## ฐานข้อมูล (supabase/migrations)

| ตาราง | เก็บอะไร |
|---|---|
| `scenarios`, `phases` | สถานการณ์และเฟส (บันทึกผ่าน RPC `save_scenario` แบบ transaction เดียว) |
| `simulation_runs` | ผลแต่ละรอบ: ค่าสูงสุด, จุดสำคัญ, กราฟเวลา |
| `places` | สถานที่สำคัญจาก OSM (seed: `supabase/seeds/places.sql`) มีคอลัมน์ PostGIS `geog` + ฟังก์ชัน `places_near(lat, lon, radius_m)` |
| `run_place_impacts` | ความลึกสูงสุดและเวลาที่น้ำถึงของแต่ละสถานที่ในแต่ละรอบ |
| `weather_cache` | cache ผลจาก Open-Meteo/ThaiWater |

นโยบาย RLS ตอนนี้เปิดให้ anon เขียนได้ (ต้นแบบในเครื่อง) — ต้องปรับก่อนเปิดใช้งานจริง

## โครงสร้างโค้ด

```
scripts/build-city.mjs     ดึงและประมวลผลข้อมูลเมือง (DEM, OSM, ภาพถ่าย) → public/city/hatyai
scripts/build-events.mjs   ข้อมูลฝน/น้ำท่าจริงของเหตุการณ์ในอดีต
src/engine/                three.js: FloodSolver (GPU), Terrain, Buildings, Roads, Water, Rain, Atmosphere, Shadows, Labels
src/sim/                   โมเดลสถานการณ์/เฟส, สุ่ม, ดึงข้อมูลจริง, preset
src/lib/repository.ts      Supabase (มี fallback เป็น localStorage)
src/ui/                    React UI (แผงเฟส, สถานที่สำคัญ, กราฟ, ไทม์ไลน์)
```
